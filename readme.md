## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/priyanshu-k1/priyanshu_portfolio_v2.git
```

**2. Navigate to the project directory**

```bash
cd priyanshu_portfolio_v2
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
