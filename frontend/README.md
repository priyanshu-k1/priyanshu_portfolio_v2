## About

This repository contains the source code for my personal portfolio website.

I built this portfolio to present my work, showcase the technologies I use, highlight the projects I've developed, and share my journey as a developer.

The website serves as a central place to explore my technical interests, development experience, and the things I'm building.

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** Project styling and UI technologies
- **Deployment:** Vercel

- Responsive website design

- Custom branding and favicon
- Optimized frontend build using Vite

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/priyanshu-k1/priyanshu_portfolio_v2.git
```

**2. Navigate to the project directory**

```bash
cd priyanshu_portfolio_v2
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
